# Student Record Management System

## Project Overview

The Student Record Management System is a console-based Java application designed to manage student information efficiently. It supports adding, viewing, searching, updating, deleting, and sorting student records.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* HashMap
* File Handling
* Collections Framework

## Features

1. Add student records
2. View all students
3. Search students by ID
4. Update student information
5. Delete student records
6. Sort students alphabetically by name
7. Sort students by CGPA in descending order
8. Save records to a text file
9. Load saved records when the application starts

## Concepts Demonstrated

* Classes and objects
* Encapsulation
* Constructors and methods
* ArrayList and HashMap
* Exception handling
* File input/output
* Comparator and sorting
* Input validation

## How to Run

### Prerequisites

Install the Java Development Kit (JDK) and Visual Studio Code.

### Compile

```bash
javac StudentRecordManagementSystem.java
```

### Execute

```bash
java StudentRecordManagementSystem
```

## Data Storage

Student records are saved in `students.txt` and loaded when the application starts.

## Learning Outcomes

This project demonstrates the practical application of Java programming, object-oriented design, collections, sorting, and file handling.
